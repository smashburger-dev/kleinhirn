# Code of conduct

kleinhirn is a small project. People ask questions here, report results
from their own devices and send their first pull requests. That should
stay possible for everyone.

## What we expect

- **Friendly and patient.** Every question is allowed. Nobody is mocked
  for not knowing something.
- **Respectful.** We criticize code, numbers and ideas, never people.
- **Open.** Everyone is welcome, regardless of experience, origin,
  gender, age, disability, religion or sexual orientation.
- **Constructive.** Whoever criticizes something says how it could be
  better, or asks.

## Not acceptable

Insults, belittling, harassment, discriminatory language, personal
attacks, publishing other people's private information, and deliberately
disrupting discussions. Flooding the repository with low-effort issues or
pull requests counts as disruption.

## If something happens

Contact the maintainers confidentially via
[@smashburger-dev](https://github.com/smashburger-dev). We listen, treat
reports confidentially and respond appropriately: from a conversation to
exclusion from the project.

## Scope

This code applies wherever the project takes place: issues, pull
requests, discussions and all other channels used in the name of
kleinhirn.

Based on the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
